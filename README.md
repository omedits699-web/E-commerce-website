# ShopHub - E-commerce Website

This is a simple e-commerce website created as a university student project for web development course.

## Features

- **Home Page**: Welcome page with hero section and featured products
- **Products Page**: Display of available products with add to cart functionality
- **Cart Page**: View added products and total price with clear cart option
- **About Us Page**: Information about the project and team
- **Contact Page**: Contact form for user inquiries
- **Login Page**: Simple login form with validation

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage for cart persistence

## How to Use

1. Open `index.html` in a web browser
2. Navigate through the pages using the navigation menu
3. Add products to cart from the Products page
4. View cart items on the Cart page
5. Clear cart when done

## Project Structure

- `index.html` - Home page
- `products.html` - Products listing page
- `cart.html` - Shopping cart page
- `about.html` - About us page
- `contact.html` - Contact form page
- `login.html` - Login page
- `styles.css` - Stylesheet for all pages
- `js.js` - JavaScript functionality

## Features Implemented

- Responsive navigation
- Product display with images
- Add to cart functionality
- Cart persistence using localStorage
- Form validation
- Clean and simple UI

## Notes

This is a student project created for educational purposes. The design is intentionally simple to demonstrate fundamental web development concepts.
